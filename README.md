# 🛠️ UtilityHub

**Empowering professionals with state-of-the-art branding and document tools.**

UtilityHub is a high-performance web application designed to streamline the creation of professional assets. From dynamic email signatures to technical resumes, it combines modern design aesthetics with powerful functionality.

---

## 🚀 Key Features

### 📧 Professional Email Signature Generator
- **Dynamic Layouts:** Choose from Classic, Modern Professional, Side Banner, and Glassmorphism templates.
- **Integrated QR Codes:** Dynamic QR generation for instant contact saving or linking to external portfolios.
- **Premium Theming:** Support for frosted glass effects, deep dark modes, and vibrant gradients.
- **One-Click Export:** Specialized "Copy for Gmail" (Rich Text) feature to preserve formatting, plus HTML and PNG export options.

### 📄 Advanced Resume & CV Builder
- **Markdown Native:** Write your resume in GFM (GitHub Flavored Markdown) with a live side-by-side preview.
- **LaTeX Integration:** Full support for mathematical and technical notation via KaTeX.
- **Pro PDF Export:** Generate high-resolution, A4-ready PDFs instantly.

### 🎭 Document Studio
- A versatile workspace supporting **Pure HTML**, **LaTeX**, or **Markdown** workflows. Ideal for developers and researchers needing custom document formatting.

### 🖼️ High-Resolution Image Utility
- Professional-grade tool for resizing, rotating, and compressing images while maintaining aspect ratio and quality.

---

## 💻 Tech Stack

- **Core:** Vanilla JavaScript, HTML5, CSS3 (Custom Glassmorphism engine)
- **Tooling:** Vite, NPM
- **Libraries:**
  - **Lucide:** Iconography
  - **html2canvas & jsPDF:** Document/Image rendering
  - **KaTeX:** LaTeX engine
  - **Marked:** Markdown processing
  - **QRCode:** Dynamic QR systems

---

## 🌟 Why UtilityHub?

UtilityHub was built to eliminate the need for multiple disparate tools. By focusing on **privacy-first processing** (all generation happens in your browser) and **visual excellence**, it provides a premium experience without the overhead of heavy frameworks.
